# 例行提示词模板（占位，无真实车辆数据）

将下列意图保存为 Grok Bot Routine 时，请改成车主自己的阈值与时区（Asia/Shanghai 示例）。
**禁止**在提示词里写死 VIN、精确家门地址、Client Secret。

## 状态轮询（安静）

```text
用 tesla 连接器做一次不唤醒的状态轮询（poll）。
若车辆在线，更新本地快照；若睡着，只记录缓存状态。
一切正常时不要给用户发消息。
仅在明显异常（例如连续鉴权失败）时简短报告类别，不要输出密钥或完整原始 JSON。
```

## 低电量检查

```text
读取最近一次车辆快照（不要为了检查去唤醒）。
若电量百分比低于车主设定阈值，在本对话提醒一次，说明电量与是否在充电（如有该字段）。
不要输出 VIN 或精确坐标；位置若开启且需要，只用粗略地名。
未低于阈值则保持安静。
```

## 周汇总

```text
汇总过去一周可见的里程与续航趋势，以及本月 API/唤醒用量（若工具可提供）。
快照缺失的日期要明确写出「无数据」，不要编造。
发给用户的文案保持简短；不要包含密钥或精确到米的定位。
```

## 傍晚缓存汇总

```text
汇总当前缓存或（若已在线）实时只读状态：电量、续航、上锁、粗略位置（仅当已授权位置）、气候、总里程、当日可见里程。
不要唤醒车辆。
将给用户的正文按约定原文或固定模板发送；不要添加密钥或调试信息。
```
