# 06 — 例行任务（Routines）

原则：例行以**缓存**为主；无异常保持安静；文案不要泄露精确隐私。

## 状态轮询

- 节奏示例：每天 08:00–20:00，每 2 小时。
- 调用不唤醒的 `poll`。
- 车已在线：更新快照。睡着：只记 offline/cached。
- 正常时可不打扰用户。

## 低电量检查

- 节奏示例：每天约 21:00。
- 使用最近快照；低于车主阈值再提醒。
- 提醒里避免贴精确坐标与 VIN。

## 周汇总

- 节奏示例：每周一次。
- 内容：可见里程、续航趋势、API/唤醒用量（如有）。
- 历史不足时明确说「快照不完整」，不要编造。

## 傍晚缓存汇总（可选）

- 节奏示例：每天约 17:00。
- 汇总当时缓存或在线实时状态；**不要为了出报告而唤醒**。

例行提示词模板见 [examples/routine-prompts.md](../examples/routine-prompts.md)。
