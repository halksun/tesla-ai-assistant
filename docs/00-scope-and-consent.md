# 00 — 范围与同意

在创建应用或写入任何密钥之前，先和车主对齐：

## 必须问清

1. 只要**查询**，还是也包括**控车**？（本 playbook 默认只要查询。）
2. 要不要**地理位置**？（默认不要。）
3. 低电量阈值？（示例：低于 40% 提醒。）
4. 车辆所在区域是否为**中国大陆**？（决定 `TESLA_REGION=cn` 与开发者站点。）

## 同意规则（建议写入 Agent 偏好）

- 查询类工具：可按约定自动使用。
- 唤醒车辆：需要车主明确说「可以唤醒」或等价确认；遵守每日/间隔预算。
- 任何控制类：每次具体动作单独确认；「帮我弄下车」不等于同意解锁。
- 禁止把密码、验证码、Client Secret、Token 贴进聊天；用安全输入或本机环境变量。

## 成功标准（只读）

- MCP 能列出车辆（VIN 脱敏展示即可）。
- 能在不唤醒的情况下返回最近缓存状态，或在车已在线时返回实时状态。
- 低电量例行只会在触达阈值时打扰车主。
- 仓库与聊天中无真实密钥、无精确隐私坐标明文。
